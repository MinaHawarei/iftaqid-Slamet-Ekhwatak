# افتقد سلامة اخوتك

تطبيق تفاعلي لخدمة وافتقاد الشباب («اجتماع شباب الملاك») لاختيار وإرسال آيات الكتاب المقدس ككروت مصممة أو نصوص عبر واتساب، مع نظام متكامل لإدارة الافتقاد وقوائم الاتصال محلياً 100% دون أي خوادم خارجية.

A professional, offline-capable, client-side React 18 + TypeScript web app for church youth visitation and Bible verse distribution via WhatsApp.

---

## المميزات الرئيسية (Key Features)

1. **طرق اختيار الآيات (Verse Picking Modes):**
   - **سحب عشوائي (Random Draw):** سحب آية مع حركة تقليب واهتزاز للكارت وتأثير ثلاثي الأبعاد مع خوارزمية تضمن عدم تكرار الآيات حتى انتهاء الدورة.
   - **اختيار رقم (Number Grid):** شبكة أرقام (1 إلى 41) مع تتبع الأرقام التي تم فتحها، وإمكانية إعادة خلط الأرقام وحفظ الترتيب تلقائياً في `localStorage`.
   - **مخصص (Custom Verse):** كتابة أي آية أو نص مخصص مع الشاهد وتوليد كارت فوري.

2. **إرسال ومشاركة واتساب ذكية ومراعية للأجهزة (Device-Aware WhatsApp Sharing):**
   - **على الموبايل:** توجيه مباشر إلى تطبيق واتساب الرسمي (`https://wa.me/...`) في نفس النافذة لضمان فتح التطبيق بسلاسة.
   - **على أجهزة الكمبيوتر (Desktop/Laptop):** فتح واتساب ويب (`https://web.whatsapp.com/send?...`) في تبويب جديد.
   - **خيارات الإرسال:**
     - **كنص:** إرسال النص منسقاً مع اسم المستلم والجملة الافتتاحية والشاهد وتوقيع الخدمة.
     - **كصورة:** رسم الكارت فائق الدقة (1080×1400) باستخدام HTML5 Canvas ونسخه مباشرة إلى الحافظة (Clipboard) ليقوم الخادم بلصقه مباشرة (Ctrl+V) في الشات دون الحاجة لتحميل وتخزين ملفات، مع دعم Web Share API وتنزيل الصورة كحل بديل.

3. **نظام الافتقاد وقائمة جهات الاتصال (Visitation & Queue System):**
   - **زر "الافتقاد" الذكي:** يظهر فقط عند وجود جهات اتصال مستوردة، ويختفي تماماً ليعمل التطبيق كالتطبيق الأصلي إذا لم يتم استيراد أي ملفات.
   - **طابور الافتقاد العادل (Fair Queue):** ترتيب المخدومين تصاعدياً حسب تاريخ آخر تواصل:
     1. من لم يُتصل بهم بعد يظهرون أولاً (مرتبين أبجدياً).
     2. المخدومون الأقدم تواصلاً يظهرون قبل الأحدث.
     3. عند التساوي في التاريخ، يتم الترتيب أبجدياً باللغة العربية.
   - **شارات أعياد الميلاد (Birthday Badges):** تنبيه مرئي إذا كان عيد ميلاد الشخص اليوم أو خلال الـ 7 أيام القادمة.
   - **شاشة جلسة الافتقاد (Visit Screen):**
     - عرض اسم المخدوم، وتاريخ آخر اتصال، وتاريخ الميلاد.
     - شرائح لاختيار رقم الهاتف في حال وجود أكثر من رقم.
     - زر **اتصال** (يفتح المتصل المباشر `tel:` على الهاتف، أو ينسخ الرقم على أجهزة الكمبيوتر).
     - زر **رسالة واتساب** يعبئ تلقائياً اسم المستلم ورقمه في كارت الإرسال.
     - استمرار الجلسة عند مغادرة التطبيق لإجراء المكالمة الهاتفية والعودة.
     - تحديث تاريخ آخر افتقاد تلقائياً مع توفير زر "تراجع" لمدة 6 ثوانٍ وإمكانية تعديل التاريخ يدوياً.
     - أزرار التنقل السريع: "التالي في الطابور" و"الرجوع للطابور".

4. **إدارة ملفات الإكسيل (Excel Import):**
   - استيراد ملفات متعددة (.xlsx / .xls / .csv) وقراءتها محلياً بالكامل بواسطة SheetJS.
   - تجاهل الصف الأول (Header).
   - قراءة: العمود B (الاسم)، العمود D (الموبايل)، والعمود G (تاريخ الميلاد).
   - دعم وجود رقمين في نفس الخلية (مفصولين بفاصلة).
   - تطهير وتوحيد الأرقام لصيغة E.164 مع دعم الأرقام المصرية (مع أو بدون الصفر) والأرقام الهندية-العربية (٠-٩).
   - دمج جهات الاتصال المتكررة بناءً على الرقم الأساسي مع الحفاظ على سجل الافتقاد (`lastContactAt`).
   - تقرير استيراد مفصل: المضافين، المحدثين، والمتخطين مع توضيح أسباب التخطي.

5. **النسخ الاحتياطي والخصوصية (Backup & Privacy):**
   - **البيانات محفوظة على جهازك فقط (Client-Only):** لا يتم إرسال أي بيانات لأي خادم إطلاقاً.
   - تصدير واستيراد النسخ الاحتياطية كملف JSON مع دعم خياري "الدمج" (Merge) أو "الاستبدال الكامل" (Replace).
   - توافق كامل وتلقائي مع المفتاح القديم `iftaqed-order-v1` لترتيب الأرقام.

## بنية ملف الإكسيل المطلوب (Excel Format Specification)

- **الصفحة:** الصفحة الأولى من الملف (First sheet).
- **الصف الأول:** صف العناوين (يتم تجاهله تلقائياً).
- **العمود B (الاسم):** مطلوب (يتم تنظيف المسافات الزائدة).
- **العمود D (الموبايل):** مطلوب (يقبل رقماً أو رقمين مفصولين بفاصلة `,` أو `،`؛ يتم اعتماد الرقم الأول كرقم أساسي).
  - الصيغ المقبولة: `01012345678`، `+201012345678`، `٠١٠١٢٣٤٥٦٧٨`، `201012345678`، أو رقمين مثل `01011112222, 01233334444`.
- **العمود G (تاريخ الميلاد):** اختياري.
  - الصيغ المقبولة: تواريخ الإكسيل التسلسلية، كائنات التاريخ، أو نصوص مثل: `YYYY-MM-DD`، `DD/MM/YYYY`، `D-M-YYYY`، أو بدون سنة `DD/MM`. في حال عدم صحة التاريخ، يتم الاحتفاظ بجهة الاتصال وتخطي التاريخ مع التنبيه في التقرير.

يوجد ملف تجريبي جاهز في:
`sample/contacts-sample.xlsx`

## قيود إرسال الصور في واتساب (WhatsApp Limitations)

- بروتوكول روابط واتساب (`wa.me` و `web.whatsapp.com`) لا يدعم إرفاق ملفات أو صور تلقائياً من الروابط لأسباب أمنية خاصة بشركة واتساب.
- **الحل المعتمد في التطبيق:**
  1. يقوم التطبيق برسم الكارت بدقة عالية ونسخه فوراً إلى الحافظة (Clipboard) كصورة PNG.
  2. يتم فتح محادثة الشخص تلقائياً على واتساب، وبمجرد الضغط على "لصق" (Paste / Ctrl+V)، تظهر الصورة جاهزة للإرسال في ثانية واحدة دون ملء ذاكرة الجهاز بصور مكررة.
  3. يدعم متصفحات الهواتف التي تتيح Web Share API للمشاركة المباشرة.
  4. في المتصفحات القديمة غير الداعمة لنسخ الصور، يتم تنزيل الصورة تلقائياً كخيار بديل.

## التشغيل والتطوير (Development & Build)

### المتطلبات
- Node.js (v18+)
- npm (v9+)

### تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### تشغيل خادم التطوير (Local Dev Server)
```bash
npm run dev
```

### تشغيل الاختبارات (Run Tests)
```bash
npm test
```
يشمل 49 اختبار وحدة (Vitest) تغطي توحيد أرقام الهواتف، تحليل التواريخ، قراءة الإكسيل، فرز الطابور، وروابط واتساب، والنسخ الاحتياطي.

### البناء للنشر (Build for Production)
```bash
npm run build
```
المخرجات تكون في مجلد `dist/` مع مسارات نسبية (`base: './'`)، مما يجعله جاهزاً للرفع المباشر على:
- Netlify
- GitHub Pages
- Cloudflare Pages
- أي خادم ويب استاتيكي أو استضافة عادية.

## English Summary

- **Offline-First & RTL Native:** Powered by React 18, TypeScript (strict), Zustand with safe versioned localStorage, and self-hosted fonts (`@fontsource/cairo`, `@fontsource/amiri`, `@fontsource/reem-kufi`).
- **Zero Network Privacy:** Contacts and visitation history never leave the user's browser.
- **Fair Visitation Queue:** Automatically prioritizes unvisited contacts, then oldest visits, breaking ties by Arabic alphabetical order.
- **Device-Aware Delivery:** Intelligently switches between `wa.me` for mobile and WhatsApp Web for desktop, with automatic clipboard image copying for seamless card pasting.
- **Excel Ingestion:** Client-side parsing via SheetJS accepting dual numbers, Arabic digits, Excel date serials, and automatic contact deduplication.
